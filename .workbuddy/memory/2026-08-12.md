# 2026-08-12 工作记录

## 任务：把短视频脚本引擎升级为多人可用的 Web 系统
用户要"人人可以登录使用"，且有 Render 账号。确认方案：邮箱+密码自助注册 / 每用户自带 DeepSeek Key(加密存服务端) / Render Postgres。

### 落地内容
- 后端 `server/`：Express + pg + bcryptjs + jsonwebtoken
  - `db.js` 建表(users + resources 通用集合表) + 新用户注册时种子默认维度池/渠道/地区
  - `encrypt.js` AES-256-GCM 加密用户 Key
  - `routes.js` 注册/登录/JWT中间件/settings(加密Key)/collections CRUD(按user_id隔离)/deepseek代理
  - `index.js` Express 同时托管 dist 静态 + SPA 回退 + /healthz
- 前端改造：
  - `lib/api.js` 带 token 的 fetch 封装；`auth/AuthContext.jsx` + `auth/Login.jsx`(登录/注册切换)
  - `store.jsx` 改为 API 驱动(保留原组件接口)，登录后 bootstrap 拉全部数据
  - `lib/llm.js` 改为走 `/api/deepseek`(后端用用户 Key，前端不持有明文)
  - `App.jsx` 未登录显示 Login，`vite.config.js` 代理 /api → localhost:3001
- 部署：`render.yaml`(Postgres free + Web Service free, 自动注入 DATABASE_URL/JWT_SECRET/API_KEY_SECRET)、`.env.example`、`README.md`
- `package.json` scripts: dev(concurrently 前端+后端) / server / build / start
